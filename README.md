# LinkerGFX

Графическая библиотека для микроконтроллеров (AVR / ESP32 / STM32).

Проект начался с учебного задания: подходящей библиотеки под мою задачу
не нашлось — и я написал свою. Первая версия библиотеки —
[TFT_EC6](https://github.com/Limpo21/TFT_EC6), она сохранена в архивном
виде. Сейчас библиотека переписывается заново: **проект в активной
разработке**, впереди большие обновления — аппаратный SPI, собственный
printf, UTF-8 и кириллица, спрайты, поддержка новых платформ.

Следите за releases.

## Статус
`v0.x — активная разработка, API может меняться`
